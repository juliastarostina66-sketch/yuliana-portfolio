# Публикация портфолио на Vercel

Сайт — Next.js 16 / React 19. Все четыре кейса доступны на одной странице. База данных, ключи API и отдельный сервер не нужны. Шрифты находятся в `app/fonts` и не загружаются с Google Fonts.

## Локальная проверка

Из корня репозитория с Node.js 24 (минимум 20.9):

```sh
npm ci
npm run lint
npm run build
npm run start
```

Для разработки используйте `npm run dev`. Перед production-сборкой остановите dev-сервер: оба используют `.next`.

## Получить публичную ссылку

1. Сохраните текущие изменения в выбранной ветке репозитория `juliastarostina66-sketch/yuliana-portfolio` на GitHub. Изменения в рабочей среде сами по себе туда не отправляются.
2. Войдите в [Vercel](https://vercel.com/new), выберите **Add New → Project** и импортируйте этот репозиторий. При необходимости разрешите Vercel доступ только к выбранному репозиторию.
3. Проверьте: **Framework Preset — Next.js**, **Root Directory — корень репозитория**, **Node.js Version — 24.x**. Команды установки и сборки можно оставить стандартными: `npm ci` и `npm run build`. Output Directory определяется Next.js автоматически.
4. Нажмите **Deploy**. После успешной сборки Vercel выдаст HTTPS-адрес проекта. Эту ссылку можно отправлять HR и клиентам.
5. Проверьте ссылку на телефоне: меню, все четыре кейса, увеличение изображений, Telegram, email и кнопку «Поделиться портфолио». Проверьте превью при отправке ссылки в мессенджер.

## Свой домен и превью ссылки

Домен можно подключить позднее через **Project → Settings → Domains**, выполнив показанные Vercel DNS-инструкции.

Для стандартного адреса Vercel дополнительные переменные не нужны: адрес для Open Graph берётся из `VERCEL_PROJECT_PRODUCTION_URL`, затем из `VERCEL_URL`. Для собственного домена добавьте необязательную переменную `SITE_URL`, например `https://your-domain.example`, и выполните повторный Deploy. Это публичный адрес сайта, не секрет.

Превью ссылки — `public/share.jpg`; описание, заголовок, Open Graph и Twitter Card находятся в `app/layout.tsx`. В production убедитесь, что `og:image` указывает на ваш публичный HTTPS-домен, а не на локальный адрес. При повторной отправке мессенджер может использовать ранее сохранённое превью.

## Обновление материалов

Тексты и факты кейсов хранятся в `app/content.ts`. У всех проектов общая структура и одинаковая визуальная система. Результат Me&Me относится к одной площадке и периоду примерно в полгода; количественные результаты других проектов не добавлены.

Изображения из HTML-прототипа находятся в `public/images/portfolio`, дополнительные материалы ЛЮМИ и MAYAK.CAMP — в существующих папках `public/images/lumi` и `public/images/mayak`. Галереи показывают макеты целиком; нажатие открывает увеличенное изображение. Лицензии локальных шрифтов сохранены в `app/fonts`.

В исходном HTML рядом с кейсом ведущего был изображён Instagram ЛЮМИ. Этот материал перенесён в галерею ЛЮМИ. Для кейса ведущего используется редакционная схема `personal-brand.svg` / `personal-brand.webp`, основанная на исходном описании работы, а не скриншот аккаунта клиента. Результат «несколько новых клиентов за первые недели» сохранён.

Публикация на Vercel и отправка изменений в GitHub — отдельные действия. Подготовленный код и успешная локальная сборка не означают, что сайт уже опубликован.
